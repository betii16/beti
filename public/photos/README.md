# Photos officielles de BETI

Pour ajouter une photo : **déposez le fichier ici avec le bon nom**, puis relancez le site (`npm run dev`) ou redéployez. Aucun code à modifier.
Tant qu'un fichier est absent, le site garde son affichage actuel (icônes) : pas de trou, pas d'image cassée.

## Fichiers attendus

| Fichier (jpg ou webp) | Où il apparaît | Format | Taille minimale |
|---|---|---|---|
| `accueil-hero` | Accroche de l'accueil (ordinateur) | Paysage 16:9 | 1600 x 900 |
| `plomberie` | Carte « Plomberie » | Portrait 4:5 | 800 x 1000 |
| `electricite` | Carte « Électricité » | Portrait 4:5 | 800 x 1000 |
| `serrurerie` | Carte « Serrurerie » | Portrait 4:5 | 800 x 1000 |
| `menage` | Carte « Ménage » | Portrait 4:5 | 800 x 1000 |
| `peinture` | Carte « Peinture » | Portrait 4:5 | 800 x 1000 |
| `demenagement` | Carte « Déménagement » | Portrait 4:5 | 800 x 1000 |
| `jardinage` | Carte « Jardinage » | Portrait 4:5 | 800 x 1000 |
| `informatique` | Carte « Informatique » | Portrait 4:5 | 800 x 1000 |
| `coiffure` | Carte « Coiffure » | Portrait 4:5 | 800 x 1000 |
| `autre` | Carte « Autre service » | Portrait 4:5 | 800 x 1000 |

Exemple : `plomberie.jpg` ou `plomberie.webp`. Pas de majuscules, pas d'accents, pas d'espaces.

Les 3 images de l'intro de l'application sont dans un autre dossier : `public/intro/1.jpg`, `2.jpg`, `3.jpg` (portrait, environ 1080 x 1920).

## Conseils

- Formats : `.jpg` ou `.webp`. Poids conseillé : moins de 300 Ko par photo (compressez avec squoosh.app).
- Cadrez le sujet au centre : les bords peuvent être rognés selon l'écran.
- Sur les cartes, le texte s'affiche en bas de la photo : évitez un sujet important dans le bas.
- Autorisation : avant de publier une photo où une personne est reconnaissable, obtenez son **accord écrit** (nom, date, usage sur le site et l'application BETI). Gardez ce document.
